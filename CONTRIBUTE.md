# Contributing to PyChannels

Thank you for your interest in contributing to **PyChannels**!

PyChannels is an open-source Python library for connecting inputs and triggers
to executable Python code.

Contributions of all kinds are welcome, including bug fixes, features,
documentation, tests, examples, and suggestions.

# Code of Conduct

Be respectful to other contributors.

Contributors are expected to:

- Treat others respectfully.
- Accept constructive criticism.
- Keep discussions focused on the project.
- Avoid harassment or personal attacks.
- Help keep the project welcoming to new contributors.

Disagreements about code or design are normal. Discuss the technical issue
rather than attacking the person.
